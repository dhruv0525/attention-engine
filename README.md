# Adaptive Attention Engine

A behavioral system that analyzes user interaction and dynamically modifies content ranking to maximize engagement.

## Features

- Real-time user behavior tracking (scroll, dwell time, clicks)
- Engagement-based ranking system
- Category preference learning
- Explore vs Exploit strategy
- Cold start handling
- Hook system (attention intervention)
- Ethical vs Manipulative mode comparison
- Live analytics dashboard

## Key Insight

This project demonstrates how modern platforms optimize for user attention and how small algorithmic changes can significantly alter user behavior.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
